# Contributing

This repository is the public product profile for [Web Document Scanner](https://web-doc-scanner.app). The commercial source code is maintained privately, so this repository does not accept code contributions or pull requests.

## Product feedback

- Try the scanner at [web-doc-scanner.app](https://web-doc-scanner.app).
- Use the [Chinese scanner](https://web-doc-scanner.app/zh/).
- Send support, privacy, or Enterprise API questions to [contact@web-doc-scanner.app](mailto:contact@web-doc-scanner.app).

GitHub Issues are not used for product support.
